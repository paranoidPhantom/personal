## The brief

The challenge was to build a tool for analyzing job applicants on the Naimix platform. The brief included an unusual requirement: using astrological charts and horoscopes in the analysis. That requirement shaped the prototype; it should not be read as evidence that these methods can assess a candidate's suitability.

## Our approach

The project involved extensive interface design, a complex backend, and a substantial frontend. I built the frontend with Nuxt 3 and Nuxt UI; the backend used FastAPI and PostgreSQL.

## The result

We placed second and won 60,000 rubles.
